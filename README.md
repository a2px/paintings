# Ashley Xie, paintings

Portfolio website for painter Ashley Xie. Live at https://a2px.github.io/paintings/

A static site: plain HTML, CSS and JavaScript, no build step. All text lives in `assets/js/content.js`.
Fonts: Unbounded and Newsreader, both under the SIL Open Font License (see `assets/fonts-public/`).
The paintings currently shown are public-domain placeholders from the Art Institute of Chicago.
